# 🌙 Runa Cafe Project

1인 사업(카페) 홍보 겸 코딩 공부용 홈페이지 프로젝트입니다.

## 📁 폴더 구조

```
Runa-Cafe_project/
├── index.html      ← 홈페이지의 뼈대 (내용 담당)
├── css/
│   └── style.css   ← 꾸미기 담당 (색, 크기, 배치)
├── js/
│   └── script.js   ← 동작 담당 (클릭, 스크롤 반응)
└── .gitignore      ← GitHub에 올리지 않을 파일 목록
```

## 🖥️ 내 컴퓨터에서 보는 방법

1. 이 저장소를 컴퓨터에 내려받습니다 (`git clone` 또는 ZIP 다운로드).
2. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
3. 코드를 수정하고 저장한 뒤 브라우저를 새로고침(F5)하면 바로 반영됩니다.

## 🌍 인터넷에 공개하는 방법 (GitHub Pages, 무료)

1. GitHub 저장소 페이지에서 **Settings** 탭 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. Branch를 `main`으로 선택하고 **Save**
4. 몇 분 뒤 `https://<내아이디>.github.io/Runa-Cafe_project/` 주소로 접속 가능!

## 📚 공부 순서 추천

1. **HTML** — `index.html`을 열어 글자를 바꿔보세요 (메뉴 이름, 가격, 주소 등)
2. **CSS** — `css/style.css`에서 색상 코드(`#6b4f3a` 같은 값)를 바꿔보세요
3. **JavaScript** — `js/script.js`에 새로운 동작을 추가해보세요
4. 익숙해지면: 사진 넣기 → 메뉴 추가 → 지도 넣기 순으로 확장
