# 🌙 프로젝트 이름

**Runa_Cafe Project (루나 카페 프로젝트)**

🌍 **홈페이지 바로가기 : https://ghdalsrl06-cloud.github.io/Runa-Cafe_project/**

## 📖 프로젝트 소개

1인 사업(카페)을 홍보하기 위한 홈페이지입니다.
메뉴판, 카페 소개, 오시는 길 정보를 한 페이지에 담아
손님들이 카페를 쉽게 알아볼 수 있도록 만들었습니다.

## 🛠️ 사용할 기술

| 기술 | 역할 |
|------|------|
| **HTML** | 홈페이지의 뼈대 (내용 담당) |
| **CSS** | 꾸미기 담당 (색, 크기, 배치) |
| **JavaScript** | 동작 담당 (클릭, 스크롤 반응) |
| **Git / GitHub** | 코드 버전 관리와 저장 |
| **GitHub Pages** | 무료 배포 (인터넷에 공개) |

## 🖥️ 실행 방법

1. 이 저장소를 컴퓨터에 내려받습니다.
   ```bash
   git clone https://github.com/ghdalsrl06-cloud/Runa-Cafe_project.git
   ```
   (또는 GitHub에서 **Code → Download ZIP**으로 다운로드)
2. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
3. 코드를 수정하고 저장한 뒤 브라우저를 새로고침(F5)하면 바로 반영됩니다.

### 인터넷에 공개하기 (GitHub Pages)

1. GitHub 저장소 페이지에서 **Settings → Pages** 클릭
2. Branch를 `main`으로 선택하고 **Save**
3. 몇 분 뒤 `https://ghdalsrl06-cloud.github.io/Runa-Cafe_project/` 주소로 접속 가능

## 💡 만든 이유

- 1인 사업(카페)을 알릴 수 있는 나만의 홍보 페이지가 필요해서
